# Neon Racers

A modern take on the classic Brick Game (Tetris handheld) motor racing game.

Dodge oncoming cars by changing lanes. Survive as long as you can across 10 levels as the speed keeps increasing.

## How to Play

- **Swipe** left / right to change lanes  
- Or **tap** the left / right side of the screen  
- Or use **Arrow keys** / **A D**

Dodge the cars coming toward you.  
Speed increases with every level.

## Features

- 3-lane racing
- 10 levels with increasing speed
- Smooth neon car graphics
- Sound effects
- High score saving
- Mobile-friendly

## Levels

| Level | Difficulty      |
|-------|-----------------|
| 1–3   | Easy            |
| 4–6   | Medium          |
| 7–9   | Hard            |
| 10    | Final Level     |

## Controls

| Input            | Action          |
|------------------|-----------------|
| Swipe Left/Right | Change lane     |
| Tap Left/Right   | Change lane     |
| ← → or A D       | Change lane     |
